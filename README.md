# NZART Voting System

## Project Description

This is an app that is a replacement for the New Zealand Association of Radio Transmitters current election system which is snail mail based which carries a significant cost to the organization.

The app has the following key features:
- Allows registered NZART members to cast their ballot for a candidate for council and president
- Allows the trusted NZART managers/employees to manage the list of valid members 
- Allows the election officer to add, edit and manage the election timeframe and candidate info
